# The Bite Journal — 54 Documented Self-Corrections

> "A method that has never bitten its author has not been run long enough."
> — the project's standing rule

Each bite = an execution error, a design flaw, or an invalid measurement, logged with cause and repair. Zero verdicts were ever consumed on a faulty instrument: every bite below was caught by a probe, a replication, or a pre-registered check BEFORE it could contaminate a result.

---

## The three canonical classes

### (a) Instrument bites — bugs in the measurement itself

- **Bite 38**: training reward computed on the sampled policy while evaluation read the greedy mode — two different objects compared as one.
- **Bite 39**: DET credit leak — the token judge paid gender agreement on any noun, not the target nouns (the "DET farm").
- **Bite 40**: EOS starvation — termination never paid → actively suppressed → greedy never stopped ("habite ×7").
- **Bite 52**: the probe selected the "best" model on the order metric, crowning the order-specialist instead of the complete run — the sealed sentence was in the data, hidden behind the wrong door.

### (b) Design bites — flaws in the experimental setup

- **Bite 47**: a reward ladder whose rung k3 suppressed the determinants required by rung k4 — the staircase closed its own next step.
- **Bite 48**: the frontier guard (≥3 sentences at max level) + one rare early capture = total training famine (4500 updates, zero gradient steps). Fixed by tiered frontiers: distillation never dies.
- **Bite 49**: three simultaneous changes — the confound, recidivist (declared after the 76-d regression).

### (c) Author bites — wrong claims by the author himself

- **Bite 42**: a "proof of existence" declared on n=1 because the number pleased him — retracted under replication (the lottery, recidivist).
- **Bite 36**: an LLM "new conversation" assumed virgin without probing — caught by the pre-registered leak probe ("how did you know?") BEFORE any verdict was consumed. The measurement was invalidated with zero verdicts spent.
- **Bite 54**: the unbalanced parenthesis.

## The count

54 bites to date: ~35 from the early arcs (router, evaluators, regex, padding, tokens, single-run standards — see the full French journal), 19 during the generation arc (Entries 75 → 78-c).

## The refuted bets (the protocol working)

Three of the author's own bets against aligned-LLM capabilities were refuted by his own measurements — each reported as a result:

- **Entry 59-b**: predicted the comprehension benchmark would fail aligned models → gpt-oss-120b passed 5/5 without the memo.
- **Entry 74**: predicted ≥2 slot-tagging failures on role-permutations → Gemini read structure perfectly (12/12).
- **Entry 77**: predicted ≥2 failures on large products → all products exact; the real finding was the echo (10÷4 → "10/4").

## One retraction

The pre-registered "proof of existence" of Entry 75-b (V-min escape, R̄ 0.641) was retracted in Entry 75-e after non-replication across three new seeds (0.19 / 0.35 / 0.50). The protocol caught the author's own confirmation bias. What survived was re-classified: partial-conditioning escapes exist on a minority of seeds.
